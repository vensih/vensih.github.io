About the project

perllogarit is a suite of free, accurate financial calculators for Albania. No registration. No paywall. No app to install. Just open the site and calculate - salary, taxes, import costs, whatever you need.

Every formula is grounded in current Albanian law and updated when the law changes. The exchange rate widget pulls live EUR, USD, and GBP rates against the Albanian Lek so that import and cross-currency calculations stay accurate without the user having to look anything up.

The design goal was to feel fast and effortless. No spinner when you type a number, no confirmation dialog to run a calculation. Every result updates instantly as you fill in the form.

What it calculates

Every day financial tools

Salary

Calculate net take-home pay from gross salary. Breaks down income tax, health insurance, and social security contributions according to Albanian tax brackets.

Self-employment Insurance

Calculate monthly social insurance contributions for self-employed individuals and sole traders, based on the declared income bracket under Albanian law.

Car Import Tax

Calculate the full cost of importing a vehicle into Albania - customs duty, VAT, and the age-based depreciation formula applied by Albanian customs authorities.

Rental Income Tax

Calculate the withholding tax owed on rental income from residential and commercial property, applying the flat rate defined in Albanian income tax law.

VAT

Add or strip VAT at Albania's standard 20% rate. Works both ways: given a net amount it outputs the VAT and gross, given a gross amount it extracts the embedded VAT.

Dividends

Calculate the net dividend after the 8% withholding tax applied to dividend distributions in Albania, useful for sole shareholder companies and S.R.L structures.

Design

Built with purpose to be fast and efficient

Instant results, no submit button

Every calculator runs as the user types. There is no form submission, no loading state, and no waiting. The output field updates on every keystroke so the user can see in real time how each variable affects the result - something a static table or a PDF can never do.

Zero friction to start

No login, no onboarding flow. The homepage lists the calculators and you click one. The tool is the page. This was intentional: Albanian users searching for a quick tax figure do not want to create an account to get it.

Glassy, lightweight interface

The UI is built around a glassmorphism design system with translucent surfaces, backdrop blur, and layered depth. Cards float above a soft gradient background, giving the site a polished, modern feel without adding visual weight or slowing down the experience.

Calculation methodology based in actual law

Each formula is derived directly from the relevant Albanian tax legislation and updated when rates or brackets change. Where the law is ambiguous or has known exceptions, a note is shown in the calculator rather than silently picking one interpretation.

Integrated Systems

Current Rates

EUR, USD, and GBP rates against the Albanian Lek are pulled from the Wise API and refreshed every 1-2 hours. The page reads the cached rate on load and displays it alongside a timestamp so the user knows exactly how recent it is. The car import calculator depends on the EUR/ALL rate, so keeping it current matters for the result to be meaningful. The most used calculators are surfaced directly on the home page so users land one click away from their answer.

Stack

Plain web, nothing extra

Markup HTML
Styles CSS
Logic JavaScript
Hosting GitHub Pages

No framework, no build step, no bundler. The entire site is static HTML, CSS, and vanilla JavaScript. That choice is not accidental - the target audience is on mobile connections in Albania where a React bundle would add meaningful load time for what is essentially arithmetic.
